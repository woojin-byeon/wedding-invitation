4.7.	Apache mpm 설정
(Include httpd-mpm.conf 주석해제)
vi /WAS/MOF/apache/conf/httpd.conf
Include conf/extra/httpd-mpm.conf
(저장 후 종료)

(아래 값은 기본 설정이며, 설치 사용자수 2000명 이상일 경우 제이니스에 문의 요청)
# vi /WAS/MOF/apache/conf/extra/httpd-mpm.conf
<IfModule mpm_prefork_module>
    ServerLimit 400
    StartServers 100
    MinSpareServers 25
    MaxSpareServers 50
    MaxRequestWorkers 400
    MaxConnectionsPerChild 10000
    KeepAlive Off
Timeout 10
</IfModule>
(저장 후 종료)
4.8.	Apache logrotate 설정
(날짜 와 주기는 고객사 요구사항에 따라 변경 가능)
# vi /etc/logrotate.d/httpd
/home/jovt_siteid/log_data/apache/*log {
copytruncate
daily
rotate 7
missingok
notifempty
dateext
}
(저장 후 종료)
4.9.	Apache 자동시작 등록
# vi /etc/systemd/system/httpd.service
[Unit]
Description=Apache HTTP Server
After=network.target

[Service]
Type=forking
ExecStart=/WAS/MOF/apache/bin/httpd -k start
ExecStop=/WAS/MOF/apache/bin/httpd -k stop

[Install]
WantedBy=shutdown.target multi-user.target
(저장 후 종료)
