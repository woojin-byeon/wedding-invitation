## about

  

    

      
금융 IT 환경에서 인프라 운영과 자동화를 담당하고 있습니다. 수작업으로 반복되던 서버 구성·점검·재해복구 절차를 Ansible과 AWX 기반의 표준 워크플로로 옮기는 일을 주로 합니다.

      
온프레미스 가상화(VMware/vCenter/ESXi)와 컨테이너 플랫폼(OpenShift/Kubernetes)을 함께 운영하면서, "왜 이렇게 동작하는가"를 끝까지 파고드는 방식으로 문제를 해결합니다. 로그와 설정 파일에서 근거를 찾고, 검증한 내용은 문서로 남겨 팀이 재현할 수 있게 만듭니다.

      
관심사는 운영 회복탄력성입니다. 장애가 나지 않게 하는 것보다, 장애가 났을 때 몇 분 안에 정해진 절차로 복구되는가에 더 큰 가치를 둡니다.

## pipeline

  
커리어를 CI/CD 스테이지로 표현했습니다.

  
    
    
  1. 
      
    
      
    
        stage: build
        
    시스템 운영 기본기
    
        
    Linux · 네트워크 · 스토리지 등 물리/가상 인프라 운영을 맡으며 장애 대응과 정기 점검 프로세스를 익혔습니다.
    
      
    
    
    2. 
    
  2. 
      
    
      
    
        stage: test
        
    가상화 · 컨테이너 전환
    
        
    VMware 기반 가상화 운영에 더해 Kubernetes/OpenShift 플랫폼 운영으로 영역을 확장했습니다.
    
      
    
    
    3. 
    
  3. 
      
    
      
    
        stage: deploy
        
    자동화 표준화 리드
    
        
    Ansible/AWX 기반 자동화 플랫폼 도입을 주도하고, 팀이 재사용할 수 있는 표준 role과 문서를 정리했습니다.
    
      
    
    
    4. 
    
  4. 
      
    
      
    
        stage: operate
        
    운영 회복탄력성 & 보안
    
        
    BCP 자동화, 컨테이너 플랫폼 보안 검증, 키 관리 표준화를 진행 중입니다.
